# Aero Tareas

Checklist con estética **Frutiger Aero**, hecho para el celular.

**Abrir:** https://aero-tareas.pages.dev/

- Se instala como app (Android: botón **Instalar**; iPhone: **Compartir → Agregar a pantalla de inicio**).
- Funciona **sin internet**.
- Tus tareas se guardan **solo en tu teléfono**; nada se envía a ningún servidor.
- **Categorías opcionales** (menú **⋯ → Nueva categoría**): separa tus tareas en listas como «Súper del día» o «Trabajo». Si no creas ninguna, todo queda en una sola lista.
- Sonidos de agua al marcar, desmarcar y quitar tareas (se apagan en **⋯ → Sonidos**).
- Copia de seguridad: menú **⋯ → Guardar copia de seguridad** (y **Recuperar desde una copia** para restaurarla o pasarla a otro teléfono).

Hecho con HTML, CSS y JavaScript, sin dependencias. Al publicar cambios, subir el número de `VERSION` en `sw.js`.
